# TEETOP — Solution Architect Career OS

A local, responsive learning dashboard for the 365-day career roadmap.

## Run
Open `index.html` in any modern browser.

## Included
- Full career phase map through Day 365
- Day 1 fully detailed
- Day 1–84 foundation navigator and phase/topic scaffolding
- 3-hour daily task structure
- Mastery checks and deliverables
- Browser-local progress tracking and notes

Progress is stored in your browser's localStorage, so use the same browser/device if you want it retained.

The later advanced phases are structured but intentionally not hard-coded with day-level resource links yet; those can be updated with current resources as you reach them.
